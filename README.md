# Kassasystem

> **School project.** This is a group project (group 3) in the course *Introduktion till testning av IT-system* (INTE) at the Department of Computer and Systems Sciences (DSV), Stockholm University, HT2026. The code was written to practise testing and is not meant for real-world use.

## About

A simplified checkout system for a shop, written in Java. The purpose of the project is to practise testing: test-driven development, unit testing, test design techniques, mocking, code review and static analysis. There is therefore no user interface and no `main` method. The system is only run through its tests.

The system can:

- register products with a price, VAT (0, 6, 12 or 25 %) and a GTIN barcode
- scan items and add them to a shopping cart
- calculate discounts: fixed, percentage, multi-buy ("3 for 2"), member and student/senior discounts
- create a receipt

Amounts are stored in öre (1/100 SEK) to avoid rounding errors.

## Requirements

- JDK 24
- Maven

## Running the tests

```bash
mvn test
```

## Reports

| Report | Command | File |
| --- | --- | --- |
| Code coverage (JaCoCo) | `mvn test` | `target/site/jacoco/index.html` |
| Static analysis (PMD) | `mvn pmd:pmd` | `target/reports/pmd.html` |

## Structure

```
src/main/java/checkout/   the system's classes
src/test/java/checkout/   JUnit 5 tests (some using Mockito)
ai-generated-tests/       tests generated by AI tools for the course's AI part (not compiled)
```
